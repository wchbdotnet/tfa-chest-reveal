# TFA Chest Reveal

Preserve the surprise at the end of The Fractured Archive.

TFA Chest Reveal hides the small-chest sparkles until the reward braziers finish lighting orange or purple. After the reveal, existing sparkles return automatically.

- Keeps the reward reveal animation visible.
- Restores the original effects when disabled.
- Requires no configuration.

This plugin changes the sparkle's presentation only. It does not predict rewards, provide combat guidance, or automate gameplay.

## Installation

Submitted for RuneLite Plugin Hub review. Once approved, search for **TFA Chest Reveal** in the Plugin Hub and install it.

## Development

Run `gradlew.bat run`, or use `launch-dev.cmd`, to open a development client.
